### M1. index.html 残留指向不存在文件的 Vite 式入口脚本，生产环境每次加载 404

- **文件**: `index.html:53`
- **维度**: 代码质量与潜在 Bug

- **代码**:
  ```html
  <body>
      <div id="root"></div>
      <script type="module" src="/src/main.tsx"></script>  <!-- src/ 下无 main.tsx，实际入口是 index.tsx -->
  </body>
  ```
- **建议**: 删除该 script 标签（Rsbuild 自动注入入口）；或改为 `/src/index.tsx` 并确认 Rsbuild 不会重复注入。

### M2. useRequest：cancel 后若 asyncFn 忽略 signal 正常 resolve，会被当作 success 写入 state

- **文件**: `src/topics/hooks/custom-hooks/lib/useRequest.ts:136`
- **维度**: 代码质量与潜在 Bug
- **描述**: `cancel()` 只做 `abortRef.current?.abort()`，不推进 `requestSeqRef`，序号校验防不住这次请求；`.then` 分支只查 `requestId !== requestSeqRef.current`，不查 `controller.signal.aborted`，与 `.catch` 分支（153 行，有 aborted 检查）不对称。若调用方的 asyncFn 不响应 AbortSignal（真实项目常见），取消后结果仍会落库并触发 `onSuccess`。站内 mock 遵守 signal 所以不触发，但 lib 定位是「可直接拷进项目使用」，这个洞会跟着被拷走。
- **代码**:
  ```ts
  .then((nextData) => {
      // 双保险之二:即使对方忽略 signal 正常返回,过期结果也丢弃
      if (requestId !== requestSeqRef.current) {
          emit({ type: 'stale', requestId });
          return;
      }
      setData(nextData);   // ← 未检查 controller.signal.aborted
  ```
- **建议**: `.then` 的 stale 检查后加 `if (controller.signal.aborted) { emit({ type: 'cancel', requestId }); return; }`，与 `.catch` 对齐；补一条「cancel 后 asyncFn 仍 resolve → 不写 data」的契约测试。

### M3. StreamRig / AgentPipeline 定时器在组件卸载时不清理

- **文件**: `src/topics/performance/ai-native/lab/components/StreamRig.tsx:47`、`src/topics/performance/ai-native/agent-lab/components/AgentPipeline.tsx:59`
- **维度**: 性能问题（内存泄漏）
- **描述**: 两个组件都用 `useRef<number[]>` 收集 setTimeout id 并提供 `clearTimers()`，但只在 `start()`/`stop()` 时调用，**没有 `useEffect(() => () => clearTimers(), [])` 卸载清理**。流式播放中途切走路由，残留定时器继续对已卸载组件 setState（React 18+ 不告警但属泄漏）。同站 `agent-chat/index.tsx:54-57` 有标准卸载 cancel，这里是不一致遗漏；治理专题自己的题库也在考这条反例。
- **代码**:
  ```tsx
  const timersRef = useRef<number[]>([]);
  const clearTimers = () => {
      timersRef.current.forEach((id) => window.clearTimeout(id));
      timersRef.current = [];
  };
  // 全文无 useEffect(() => () => clearTimers(), [])
  ```
- **建议**: 两个组件各加 `useEffect(() => () => { cancelledRef.current = true; clearTimers(); }, [])`。
